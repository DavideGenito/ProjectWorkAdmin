## Comandi Angular

* **Create new project:** `ng new "nome"`
* **Build and start:** `ng serve` (`-o` per aprire subito sul browser)
* **Creare component:** `ng g c components/"nome"` (o qualsiasi nome di sottocartella; usa `--skip-tests=true` per non generare il file di test)
* **Creare service:** `ng g s services/"nome"` `--skip-tests=true`
* **Quando cloni da git per eseguire (caricamento librerie):** `npm i`
